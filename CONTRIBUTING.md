# Contributing

1. Pick the folder that fits your topic (or propose a new one in an issue).
2. Copy `docs/templates/note.md` to `docs/<folder>/<kebab-case-title>.md`.
3. Keep notes focused: one topic per file, with runnable examples where possible.
4. Cite sources and link related notes.
5. Open a pull request with a short description of what you added or fixed.
